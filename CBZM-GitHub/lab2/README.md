# Lab 2 – Transakcje i Proof of Work

Wymagany Python 3.10 lub nowszy. W katalogu `lab2` uruchom:

```powershell
python experiments.py
```

Program wyświetla pełny łańcuch, mierzy czasy wydobycia dla trudności 1–6,
sprawdza integralność, walidację transakcji oraz korzeń Merkle. Zapisuje
surowe pomiary do `pomiary.json`. Pomiar dla trudności 6 może potrwać
kilkadziesiąt sekund lub dłużej. Wystarcza biblioteka standardowa Pythona.
