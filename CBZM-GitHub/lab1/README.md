# Lab 1 – Prototypowy blockchain

Wymagany Python 3.10 lub nowszy. W katalogu `lab1` uruchom:

```powershell
python blockchain.py
```

Program wyświetla łańcuch, skróty bloków, wpływ kolejności kluczy JSON
oraz wyniki prób modyfikacji danych. Do uruchomienia programu wystarcza
biblioteka standardowa.

Polecenia do przygotowania środowiska zgodnie z instrukcją laboratorium:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m pip list
```
